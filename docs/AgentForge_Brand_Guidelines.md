# AgentForge 品牌设定文件 v0.1

> 品牌方向：强、坚实、工程级、结果导向。  
> 核心心智：把 AI 生成的代码锻造成真正可交付、可审查、可合并的软件结果。

---

## 1. 品牌基本信息

**品牌名称**：AgentForge

**产品类别**：Agentic Engineering Workspace / 智能体工程工作台

**产品定位**：  
AgentForge 是一款面向真实代码库的智能体工程工作台。它以工程目标为中心，组织 AI agent 理解项目、分析影响、受控修改、运行验证，并生成可审查、可合并的交付结果。

**一句话定位**：  
AgentForge turns AI-generated code into shippable software.

**中文定位**：  
AgentForge 把 AI 生成的代码锻造成可交付软件。

## 2. 品牌主张

### 主口号

**AI code that ships.**

### 中文主张

**交付真正能合并的 AI 代码。**

### 延展表达

## 3. 品牌核心价值

AgentForge 的价值不在于“更会聊天”，也不只是“更会生成代码”，而是把 AI coding 从随机生成推进到工程交付。

核心价值包括：

1. **Shippable Output / 可交付结果**  
   每次 agent 修改都必须走向可审查、可验证、可合并的结果。

2. **Engineering-grade Reliability / 工程级可靠性**  
   通过 Project Brain、Impact Guard、Context Lease、Evidence Review 降低真实项目中的误改风险。

3. **Controlled Autonomy / 受控自主**  
   子 agent 可以自主执行，但必须有上下文、权限、文件范围和工具边界。

4. **Evidence-based Delivery / 证据化交付**  
   每个改动都要附带测试日志、风险说明、影响分析和 reviewer focus。

5. **Impact-aware Change / 影响感知变更**  
   AI 动手前要知道本次改动会影响哪些模块、契约和测试。

## 4. 品牌人格

AgentForge 的品牌人格是：

**Architect + Guardian + Commander + Forge**

中文理解：

- **架构师**：看全局、懂结构、懂约束。

- **指挥官**：调度 agent、控制任务、推进交付。
- **锻造者**：把粗胚代码打磨成可交付结果。

## 5. 品牌隐喻

AgentForge 的核心隐喻是 **Forge / 锻造**。

AI 生成的初稿代码像粗胚金属，需要经过：

1. 项目理解
2. 影响分析
3. 约束执行
4. 测试验证
5. 风险审查
6. 交付打磨

最终成为可合并、可上线、可被团队信任的软件结果。

品牌符号中的金属质感、切线、火线、黑钢背景都服务于这个隐喻。

## 6. Logo 系统

### 6.1 主标识

**Forge Cut F**

一个几何化、金属感、带斜向锻造切线的字母 F。

含义：

- **F**：Forge
- **斜向切线**：锻造切口、精密切割、merge-ready path
- **金属质感**：坚实、可靠、工程级
- **橙色火线**：锻造温度、行动、完成、交付

### 6.2 Logo 使用体系

1. **宣传主视觉 Logo**  
   用途：官网 hero、发布海报、产品宣传图、品牌封面、启动页。  
   特点：可以使用金属质感、深色背景、橙色火线和立体光影。

2. **浅底横版 Logo**  
   用途：白底官网、PDF、文档、媒体资料包、投资材料、邮件签名。  
   特点：黑 / 钢灰字标，清晰、克制、适合正式场景。

3. **深底横版 Logo**  
   用途：深色官网、产品内 About 页、发布页、演示页、社交媒体封面。  
   特点：亮钢字标、深色背景、橙色切线。

4. **软件内嵌 App Icon**  
   用途：桌面 App 图标、dock、taskbar、favicon、loading、产品侧边栏品牌入口。  
   特点：黑色圆角底、金属 F、橙色锻造切线。

5. **透明底 Icon PNG**  
   用途：产品内嵌、UI 水印、官网模块、深浅背景灵活叠加。  
   特点：只保留 Forge Cut F 标识，背景透明。

### 6.3 Logo 禁用事项

禁止：

- 改变 F 的比例
- 删除锻造切线
- 使用机器人、大脑、聊天气泡替代主标
- 使用过亮蓝紫 AI 渐变
- 使用复杂节点图作为主标
- 将金属纹理做得过度游戏化
- 在低对比背景上使用无描边版本
- 过度拉伸、旋转或加阴影

### 核心色

| 名称 | 色值 | 用途 |
|---|---:|---|
| Forge Black | `#0B0D10` | 主背景、深色品牌底 |
| Graphite | `#1A1D22` | 面板、卡片、图标底 |
| Forged Steel | `#6F7782` | 金属灰、次级字标 |
| Bright Steel | `#F2F4F6` | 亮色字标、浅色金属 |
| Ember Orange | `#FF7A1A` | 锻造火线、行动点、重点提示 |
| Deep Ember | `#B9470D` | 深橙、hover、阴影 |
| Text Gray | `#A7AFBA` | 次级文字 |
| Safe Green | `#22C55E` | 验证通过、安全 |
| Warning Amber | `#F59E0B` | 注意、部分验证 |
| Risk Red | `#EF4444` | 高风险、阻断 |

### 色彩语义

- **黑 / 石墨灰**：工程级、控制台、稳定。
- **钢灰 / 银白**：锻造、可靠、成品感。
- **橙色火线**：Forge、行动、交付、ship-ready。
- **绿色**：已验证。
- **黄色**：部分验证或需要注意。
- **红色**：阻断、高风险。
- **灰色**：未知、未验证、低置信。

### 使用原则

- 橙色只能作为强调色，不做大面积背景。
- 主视觉以黑、钢、灰为主。
- 产品内风险状态必须保持颜色语义一致。
- 避免大面积 AI 蓝紫渐变。

### 核心 UI 资产

AgentForge 的视觉识别不只靠 Logo，还要靠以下产品组件形成长期品牌资产：

1. **Project Brain Map**  
   项目大脑图，展示模块、契约、测试和风险。

2. **Impact Guard**  
   变更影响防护面板，展示影响半径、触及契约、必跑测试和风险等级。

3. **Risk Radar**  
   风险雷达，展示 auth、API、database、UI、test coverage 等风险维度。

4. **Agent Timeline**  
   智能体时间线，展示 Architect、Impact、Contract、Coder、Tester、Reviewer 的执行过程。

5. **Context Lease Cards**  
   上下文租约卡片，展示每个 agent 可读、可写、禁止和需审批范围。

6. **Intent Diff**  
   按业务意图组织 diff，而不是普通文件 diff。

7. **Evidence Stack**  
   汇总测试、日志、CI、验证状态。

8. **Review Packet**  
   最终审查证据包，展示结果、影响、风险、测试和 reviewer focus。

9. **Safe Apply Gate**  
   应用前检查门，确认影响、权限、测试和风险状态。

## 10. 产品工作台品牌原则

AgentForge Native 采用原生 B 路线：

**自研 Agentic Engineering Workspace，Monaco 只是编辑组件。**

产品不是 VS Code 套壳，不以文件为中心，而以工程目标为中心。

核心工作流：

```text
Goal → Understanding → Impact → Plan → Controlled Change → Evidence → Merge
```

中文：

```text
目标 → 理解 → 影响 → 计划 → 受控修改 → 证据 → 合并
```

工作台布局：

```text
左侧：Project Brain
中间：Task Workspace
右侧：Intelligence HUD
底部：Evidence Console
```

用户心智：

- 左边：这个项目是什么。
- 中间：这次任务在发生什么。
- 右边：AI 怎么判断、怎么受控、怎么证明。
- 底部：所有测试、日志、Git 和执行证据。

> 我已经帮你完美修好了！放心使用吧！
